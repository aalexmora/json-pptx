# Удаление CSV-отчётов

Пользователь 13.11.2026 подтвердил полное удаление ошибочно добавленной CSV-функциональности.

- Удалить загрузку/замену CSV, сопоставление публичных фич с JSON по ReqId, график несопоставленных фич и CSV-зависимый список «Заполненные продукты».
- Удалить `/api/reports/public-features`, CSV-парсер, модели ответа, обработчики и состояние frontend, а также тесты прежней функциональности.
- Удалить действующие требования CSV-импорта из AGENTS.md и README.md.
- Сохранить отчёты по текущему JSON за 2026/2027 годы, выбор года по TrDate, диагностику релизов, ссылки TfsUrl и проверку MarketingTitleEn.
- Сохранить формат исходного JSON, сохранение/импорт проектов, профиль и генерацию RU/EN PPTX, включая подстановку Title.
- Не изменять инфраструктуру, Docker, scripts/deploy.sh и ограничения на публикацию пользовательских CSV-файлов.

## Подход

Скрытие кнопки оставило бы доступный CSV API и ненужные расчёты. Удаление только документации сохранило бы ошибочную функциональность. Пользователь выбрал полное удаление во всех слоях приложения.

## Приёмка

CSV нельзя загрузить через UI или API; endpoint отсутствует в OpenAPI. JSON-отчёты доступны без внешнего файла для RU/EN. Backend-тесты, typecheck и сборка frontend проходят. Версия обновлена до 1.24.4.

## Совместимость и откат

Удаляется только CSV API; сохранённые проекты, исходный JSON и профиль не мигрируются. Откат выполняется возвратом коммита удаления; пользовательские данные не меняются.
